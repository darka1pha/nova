# Mobile Architecture & Development Guide

This mobile project was generated by **Nova** using **React Native** and **Expo**.

## Why Expo for Nova Mobile

1. **Production Standard**: Expo is the officially recommended framework for React Native by Meta and the React team.
2. **Unified Tooling**: Seamless support for iOS, Android, and Web from a single codebase.
3. **EAS Build Integration**: Cloud and local builds without requiring complex Xcode/Android Studio manual configuration on every machine.
4. **Hermes Engine & New Architecture**: Pre-configured with React Native 0.76+ and Hermes bytecode compilation.

## Scripts

```bash
npm start          # Start Metro bundler with Expo CLI
npm run ios        # Launch on iOS Simulator
npm run android    # Launch on Android Emulator
npm run web        # Launch in browser via React Native for Web
npm run typecheck  # Run TypeScript verification
npm run lint       # Run ESLint checks
```

## Adding Native Modules

To install native packages (e.g. Camera, Location, SecureStore):

```bash
npx expo install expo-camera expo-location expo-secure-store
```

`npx expo install` automatically chooses compatible versions for your installed Expo SDK.

## Building for App Store & Google Play

Using Expo Application Services (EAS):

```bash
npm install -g eas-cli
eas login
eas build --platform all
```

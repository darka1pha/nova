# __PROJECT_NAME__

Enterprise-grade Next.js starter generated by **create-enterprise-next** -
App Router, TypeScript (strict), Tailwind, shadcn/ui-style components,
built-in i18n, a type-safe API layer, and automatic auth token rotation.

## Getting started

```bash
__INSTALL_CMD__
__DEV_CMD__
```

Then fill in `.env` (copy from `.env.example`) before hitting any real
backend endpoints.

## Documentation

Start with [`docs/folder-structure.md`](./docs/folder-structure.md), then
browse the rest of `docs/` for guides on the API layer, authentication,
Server Actions, fetch patterns, forms, i18n, and how to add a new feature.
Major modules also have a local `README.md` (see `src/lib/api/`,
`src/lib/auth/`, `src/features/auth/`, `src/i18n/`).

## Stack

- Next.js (App Router) + React + TypeScript (strict mode)
- Tailwind CSS + __UI_LIBRARY__
- next-intl (i18n, RTL-ready)
- React Hook Form + Zod
- Custom fetch client with retries, timeouts, and token-refresh handling
